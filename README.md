# 🫧 Implementação do Método Bolha (Bubble Sort)

Este repositório contém o código-fonte de uma implementação simples do algoritmo de ordenação **Bubble Sort** (conhecido em português como Método Bolha).

## Contexto do Projeto

O código foi desenvolvido como parte de um trabalho acadêmico (seminário) para a disciplina de algoritimos na fundação educacional do municipio de assis [FEMA], sob a orientação do Professor Luiz Ricardo Begosso.

O objetivo principal foi estudar o funcionamento, a complexidade e a aplicação prática deste algoritmo de ordenação.

## Sobre o Algoritmo

O Bubble Sort é um algoritmo de ordenação que compara repetidamente elementos adjacentes e os troca se estiverem na ordem errada. O processo é repetido até que nenhuma troca seja necessária, indicando que a lista está ordenada.

-   **Complexidade de Tempo (Pior Caso):** $O(n^2)$
-   **Complexidade de Espaço:** $O(1)$
